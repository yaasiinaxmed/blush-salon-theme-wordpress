A soft pink classic theme for beauty salons, spas and makeup studios with full Elementor compatibility.

== Description ==
Blush Salon includes full Elementor page builder compatibility, a designed home page, About, Services, Pricing and Contact page templates,
custom post types (Services, Testimonials, Team, Pricing Plans, FAQs), booking, contact and
newsletter forms that save entries in the admin and send an email, Customizer options, shortcodes for all theme modules, and a
demo content importer (Appearance > Blush Salon Setup).

== Changelog ==
= 1.2.0 =
* Demo layouts are now fully editable in Elementor. Opening Home, About, Services, Pricing or Contact in Elementor loads the sections as real widgets (headings, text, buttons, icons, background and collage images).
* Dynamic sections (services, pricing, team, testimonials, FAQs, forms, logos, map) are added as Shortcode widgets.
* Nothing is saved until you click Publish/Update in Elementor.

= 1.1.1 =
* Fixed "the content area was not found" error when editing pages with Elementor. Templates now always call the_content() while a page builder editor is open.
* Added support for all major page builders: Elementor, Beaver Builder, Divi, WPBakery, SiteOrigin, Brizy and Bricks.
* The selected page template (e.g. Elementor Full Width) is now respected on the static front page.
* Pages designed with a page builder are rendered edge to edge; other pages keep the demo layout.
* Added automatic GitHub releases.

= 1.1.0 =
* Added full Elementor compatibility across all templates (Home, About, Services, Pricing, Contact, and Default Pages).
* Added "Elementor Full Width" page template.
* Added shortcodes for all theme modules (booking form, quick bar, services, pricing, testimonials, team, FAQs, contact form).
* Added Elementor Pro Theme Builder locations support.
